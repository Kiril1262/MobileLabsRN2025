# 📌 Запуск проекту

## 🔹 Клонування репозиторію

```sh
git clone <URL_РЕПОЗИТОРІЮ>
cd <ІМ'Я_ПАПКИ_ПРОЕКТУ>
```

## 🔹 Встановлення необхідних залежностей

```sh
npm install
```

## 🔹 Старт проєкту

```sh
npx expo start
```

## 🚀 Вибір способу запуску додатку

```sh
# Запуск у браузері
w

# Запуск на Android-емуляторі
a

# Запуск на iOS-емуляторі (лише для macOS + Xcode)
i
```

📱 Або скануйте QR-код у Expo Go (для реального пристрою).

💡 **Приємного кодування та виконанання відповідних завдань!** 🎉
